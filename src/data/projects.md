## 06 — Nexa Messenger

**Category:** WhatsApp Business SaaS Platform  
**Role:** Web Developer  
**Technologies:** MySQL, Laravel, Web Development

### Description

Nexa Messenger is a SaaS platform for WhatsApp Business services powered by Meta's API, supporting marketing messages, automated replies, template management, and agent-based customer communication.

I was initially responsible for maintaining and enhancing the existing web application. As the business model evolved due to changes in Meta's pricing and policies, I became responsible for migrating existing business processes and implementing the new wallet-based pricing model.

### Scope

- WhatsApp Business integration
- Message broadcasting
- Agent-based chat
- Template management
- Wallet management
- Split budget
- Usage-based pricing
- Overage handling
- Hard-block configuration
- Usage reporting
- Margin reporting
- Broadcast cost estimation
- Broadcast balance reservation
- Wallet reconciliation
- Webhook retry and logging
- Meta API migration

### Achievements

- Migrated the platform from the existing usage model to a wallet-based business model.
- Implemented separate Blast and Service budget pools.
- Implemented configurable Overage and Hard-Block behavior per client.
- Implemented usage-based pricing and rate-card-driven calculations.
- Implemented broadcast usage estimation before message delivery.
- Implemented balance reservation before broadcast execution to prevent concurrent overuse.
- Implemented reconciliation of reserved usage against final delivery status.
- Implemented usage and margin reporting based on wallet and cost ledgers.
- Implemented webhook retry and delivery logging for improved reliability and auditability.
- Supported migration of existing WhatsApp accounts to the new Meta App ID structure.
- Migrated existing business processes into the new system behavior.
